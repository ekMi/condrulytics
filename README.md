# Condrusian Challenge Data Analysis (2006–2025)

This project aims to explore and analyze historical data from the Condrusian Challenge between 2006 and 2025.

## Objectives

- Extract structured data from PDF race rankings
- Build a clean and usable dataset over multiple years
- Analyze performance trends and athlete progression
- Develop predictive models for future results
- Create an interactive dashboard (Streamlit) for data exploration

## Project Pipeline

1. **Raw data unzipping**  
   Unzipping orinal datasets fetched from https://challengecondrusien.com/archives/

2. **PDF Parsing**  
   Convert raw ranking PDFs into structured data

3. **Data Cleaning & Structuring**  
   Standardize names, times, categories, and formats

4. **Exploratory Data Analysis (EDA)**  
   Identify trends, patterns, and key insights

5. **Modeling & Predictions**  
   Experiment with machine learning models to predict performance

6. **Visualization**  
   Build an interactive dashboard using Streamlit

## Tech Stack (planned)

- Python
- Pandas / NumPy
- PDF parsing tools (e.g. pdfplumber, PyMuPDF)
- Scikit-learn / ML models
- Streamlit (dashboard)

## Status

Project in early development — structure and features will evolve over time.
